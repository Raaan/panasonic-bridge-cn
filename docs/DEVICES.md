# 设备与协议说明

目前使用并验证的设备为 F-75C5PJD 净化器、CS-JM35K410Q 空调和 NR-E411BG-NH 冰箱，现有已实现控制均可用。这里整理其识别条件、协议字段和使用上的限制，便于维护及新增型号适配。

## F-75C5PJD 净化器

识别条件为类别 `0810`、规范化子类型以 `75C5PJD` 开头，且云端型号等于 `F-75C5PJD`。它与部分社区资料中的 `0830` Aircle 不是同一类别。

- 读取：`ADevGetStatusNeedsAP`；控制：`ADevSetStatusNeedsAP`。
- 电源 `runSta` 为 0/1；模式 `runM` 为轻柔 0、自定义 1、消毒 2、智能托管 3。
- 自定义风量低／中／高为 2/3/4。选择轻柔会切换到轻柔模式，跨模式选择低中高会发送 `runM=1` 与目标风量，不会隐式开机。急速 5 不作为普通自定义档提供。
- NanoeX、童锁、指示灯和显示屏按返回的布尔状态提供控件。等离子体 `uvSterilization` 仅在开机且自定义模式下可调。
- 扩展模式状态来自完整缓存，使用前需与实时电源、风量和 NanoeX 一致。
- 保留协议字段 `fliterRemind` 的原拼写；当前没有滤网复位功能。未确认单位的读数按原始诊断值保留。

## CS-JM35K410Q 空调

识别条件为类别 `0900`，规范化子类型以 `AIRCONCOMMON202401` 开头。云端型号文本可能缺失，缺失时显示协议名称。其他同类别设备仍需核对控制器与协议。

- 读取：`ACDevGetStatusInfoAW`；控制：`ACDevSetStatusNewProtocol`。
- 电源运行 48、停止 49；制冷 66、制热 67、除湿 68；设温 16–30℃，整数步长。
- 风速自动 65、20% 49、40% 50、60% 52、80% 54、100% 55。
- 风向、NanoeX、睡眠、辅热、强智冷暖和柔湿制冷按设备运行模式及支持标记开放。例如辅热只在开机制热时可调。
- 灯光含义为 `lamp=0` 亮、`lamp=1` 灭。
- 普通控制从最新状态的白名单字段构造请求；灯光与关机使用单字段请求。关机首次未确认时会再延后读取一次，不重复发送。
- 室温编码仍未确认，`current_temperature` 保持 `None`，不将原始 128 解读为室温，也没有外部传感器回退。
- 当前没有 auto、fan_only、内部洁净、定时及能耗等全部 App 功能。

## NR-E411BG-NH 冰箱

识别条件为类别 `0100`，规范化子类型严格为 `FRIDGE19`。代码按协议族识别，设备信息显示 Fridge-19；目前的实机结果对应 NR-E411BG-NH。

- 读取：`FDevGetStatusInfo`；控制：`FDevSetStatusInfo`，控制请求带对应会话头。
- 冷藏 `PCTempSet` 为 2–7℃，变温室 `SCS1TempSet` 为 -3–4℃，冷冻 `FCTempSet` 为 -23–-17℃，步长均为 1。
- 六项功能为速冻、快速制冰、制冰停止、新鲜冻结、节能导航和 NanoeX。
- 控制使用 24 个官方字段，加 `isTodoLimit=1`。每次接受一个用户目标，并按规则处理互斥项：快速制冰清除制冰停止及新鲜冻结，后两项开启时清除快速制冰。
- 三个温区必须有最新且合法的设定值；缺失的其他可选字段按 0 处理。适配其他型号时需要确认这一行为不会改变无关设置。

温区范围的早期整理参考了 [NR-E411BG 说明书](https://home.panasonic.cn/support/attachments/auld/manual/NR-E411BG.pdf)。当前设备确认情况统一记录在 [VERIFICATION_STATUS.json](VERIFICATION_STATUS.json)，早期定位过程见 [排障记录](DEBUGGING_CASES.md)。
