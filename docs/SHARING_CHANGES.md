# 接收与分享修改 / Sharing changes

欢迎在自己的 fork 中修改，也欢迎把有用的改动提交回来，方便其他用户一起使用。

## 提交和合入

1. 在独立分支修改，提交 PR 并说明问题、型号、来源和测试结果。
2. 我会结合现有代码检查兼容性、隐私和测试情况，必要时一起调整。
3. 合入后保留作者归属和原有署名，并在更新记录或型号说明中注明相关贡献。
4. 其他用户可以按对应许可证继续使用、修改和分享。正式版本会另行整理发布说明和验证结果。

如果代码先发布在其他 fork、帖子或补丁中，建议请作者直接提交 PR，或先确认许可及署名方式。调试资料请先脱敏，保留对复现有用的字段即可。

适合回馈上游的通用改动，可以另行整理并与对应项目讨论。具体开发要求见 [贡献指南](../CONTRIBUTING.md)，许可与来源见 [第三方说明](../THIRD_PARTY_NOTICES.md)。

## English

Forks and improvements are welcome. Submit changes in a separate branch with the affected models, sources and test results. I will review compatibility and privacy before merging, keeping the contributor's authorship and existing notices.

Others may use and share merged changes under the applicable licenses. For work first published elsewhere, establish the reuse terms and attribution or invite the author to submit a PR. Sanitize debugging records before sharing them. General fixes that also help upstream projects can be prepared and discussed separately.
