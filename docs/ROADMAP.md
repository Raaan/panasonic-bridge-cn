# 维护计划 / Maintenance plan

目前优先把已有设备适配维护好，再逐步增加型号。净化器、空调和冰箱已经在家中稳定使用，后续工作主要放在安装升级、异常处理、资料整理和社区测试上。

## 近期工作

1. 核对历史证书来源，整理证书更新方式。
2. 完善安装、升级、卸载和会话失效时的处理。
3. 继续补设备和固件测试记录，尤其是其他用户使用相同型号的结果。
4. 整理代码和协议来源，保留原有许可与署名。
5. 完成 HACS/hassfest 及发行检查后，再确定正式版本。

## 新型号与社区协作

优先判断新设备是否能复用现有协议，再增加必要的适配。尚未确认的型号或能力应有清楚标记，避免影响已经验证的设备。欢迎提交脱敏状态、实机结果和修改建议。

现有项目若增加了相同型号支持，也会重新比较并考虑协作，减少重复维护。目录收录、向上游提交改动和正式发版会分别推进。

## English

The immediate priority is maintaining the devices already in use. Work will focus on certificate provenance, setup and upgrade behavior, session handling, source attribution, packaging checks and feedback from other owners.

New models should reuse existing protocols where possible and be tested separately before support is announced. Collaboration with related projects is welcome when it reduces duplicate maintenance.
